# Unreal-Engine-Internals

这是一个持续更新中的 Unreal Engine 底层原理探究合集。仓库的目标不是停留在 UE 功能应用层的浅尝辄止，而是尽量用易懂、系统、贴近底层实现的方式，把引擎内部的核心机制讲清楚：它是什么、为什么这样设计、底层大致怎么运作、它如何支撑应用层。

对于不甘于只写 Gameplay 代码、希望真正理解引擎的朋友，本系列会围绕线程模型、对象系统、垃圾回收、反射、网络同步、渲染管线等核心子系统展开深入解析。虽然谈不上逐行细究源码的级别，但已力求讲清楚 UE 的系统设计以及底层运作模型。读完后，你应该能对"引擎是如何工作的"建立起一张相对完整的图，也能更从容地面对游戏开发面试中关于引擎原理的追问。

## 适合谁阅读

本系列并不是面向完全零基础同学的入门教程，也不是照抄官方文档的功能说明书。它更适合已经写过一些 UE 代码（C++ 或蓝图）、对引擎基本工作流有体感，并且希望往下走一层、理解引擎内部机制的朋友。

如果你正在准备游戏开发方向的面试，建议把它当作"理解型八股"来读：不要只记结论，多关注每个机制背后的设计动机和代价。如果你是为了系统学习引擎原理，也可以按合集顺序慢慢看，把文中的例子、图示和代码片段结合起来理解。

## 阅读建议

每篇文章通常会先讲概念与设计动机，再讲底层机制，最后补充容易被追问的细节。建议阅读时多问三类问题：

1. 这个机制解决了什么问题？
2. 它依赖哪些底层结构？
3. 它带来了哪些代价或边界？

这样学到的内容会比单纯背结论更稳定，也更容易在实际开发和面试追问中展开。
